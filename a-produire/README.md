# À produire pour Actu-Basics

Quand JG **maîtrise** un module (séances faites, exercices de code réussis, contrôle de compréhension validé),
un fichier `a-produire/<module>.md` est déposé ici, par exemple `a-produire/A3.md`.
Le projet Actu-Basics s'en sert pour produire la fiche et la vidéo du module.

Règles :

- Partir de [`_modele.md`](_modele.md) et garder ses cinq sections, dans cet ordre.
- Texte **rédigé de zéro**. Aucun extrait, aucune paraphrase proche d'un support de cours ou d'un livre. Les ouvrages sont cités par titre, édition et chapitre seulement.
- Chaque chiffre vient d'une séance du dépôt, et il est donc recalculé par `tests/test_contenus.py`.
- Le fichier est déposé par une PR, après accord de JG.
- Il ne lance rien tout seul : la fiche, la relecture (ChatGPT ou autre) et la vidéo suivent le circuit d'Actu-Basics, et JG valide avant tout rendu.
