# Suivi personnel

Ce dossier contient **uniquement les notes et le code de JG** : diagnostic par compétence, plan, notes de séance, journal de progression.

Ne jamais y mettre :
- les supports de cours (ils restent dans la bibliothèque du projet, hors de tout dépôt) ;
- le CV ou des données personnelles (adresse, téléphone, employeur, dates, projets de vie).

| Fichier | Contenu |
|---|---|
| `diagnostic.md` | Ce que je maîtrise, ce qui est fragile, ce qui manque, module par module (A1 à A8), dans mes mots. |
| `plan.md` | L'ordre des séances et le rythme visé. |
| `progression.md` | Une ligne par séance faite : date, module, ce que j'ai compris, ce que je dois revoir. |
| `notes/` | Mes notes de séance, une par fichier. |
